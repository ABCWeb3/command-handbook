# أوامر Arch Linux الخاصة

## مزامنة المستودعات وترقية النظام

```bash
sudo pacman -Syu
```

## البحث والتثبيت

```bash
pacman -Ss package-name
```

```bash
sudo pacman -S package-name
```

## الحزم المثبتة

```bash
pacman -Q
```

> [!WARNING]
> راجع أخبار Arch الرسمية قبل الترقيات الكبيرة التي قد تتطلب تدخلاً يدوياً.
