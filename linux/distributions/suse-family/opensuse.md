# أوامر openSUSE الخاصة

## تحديث بيانات المستودعات والنظام

```bash
sudo zypper refresh
```

```bash
zypper list-updates
```

```bash
sudo zypper update
```

## البحث والتثبيت

```bash
zypper search package-name
```

```bash
sudo zypper install package-name
```

## عرض المستودعات

```bash
zypper repos
```
