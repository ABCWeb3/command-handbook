# أوامر Kali Linux الخاصة

Kali مبني على Debian ومخصص للاختبارات الأمنية المصرح بها.

## تحديث Kali

```bash
sudo apt update
```

```bash
sudo apt full-upgrade
```

## حزم Kali الوصفية

```bash
apt search kali-linux
```

```bash
apt depends kali-linux-default
```

> [!IMPORTANT]
> استخدم أدوات Kali على أنظمتك أو ضمن نطاق لديك تصريح واضح لاختباره فقط.
