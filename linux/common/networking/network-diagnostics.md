# الشبكات وتشخيصها — أوامر مشتركة

## عرض عناوين الشبكة

```bash
ip -brief address
```

يعرض الواجهات وحالتها وعناوين IP بصورة مختصرة.

## عرض جدول التوجيه

```bash
ip route
```

ابحث عن السطر الذي يبدأ بـ `default via` لمعرفة البوابة الافتراضية.

## اختبار الوصول إلى البوابة

استبدل العنوان ببوابتك الفعلية:

```bash
ping -c 4 192.168.1.1
```

الخيار `-c 4` يرسل أربع حزم فقط.

## اختبار DNS

```bash
dig example.com
```

اختبار خادم DNS محدد:

```bash
dig @192.168.1.50 example.com
```

## تتبع مسار الاتصال

```bash
tracepath example.com
```

يعرض القفزات التي تمر بها الحزم وقد يساعد في تحديد موضع انقطاع الاتصال.

## عرض المنافذ المستمعة

```bash
ss -lntup
```

- `-l`: المنافذ المستمعة.
- `-n`: أرقام بدلاً من تحويل الأسماء.
- `-t` و`-u`: TCP وUDP.
- `-p`: العملية المالكة للاتصال عند توفر الصلاحية.

## اختبار منفذ TCP

```bash
nc -vz 192.168.1.190 5000
```

- `-v`: تفاصيل النتيجة.
- `-z`: اختبار الاتصال دون إرسال بيانات تطبيقية.

## فحص استجابة HTTP

```bash
curl -I http://192.168.1.190:5000
```

الخيار `-I` يطلب رؤوس HTTP فقط.

## حالة NetworkManager

```bash
nmcli device status
```

هذا الأمر متاح عندما يستخدم النظام NetworkManager.
