# الأمان واختبار الشبكة المصرح به

> [!IMPORTANT]
> استخدم أوامر الفحص على أجهزتك وشبكاتك فقط، أو بعد الحصول على تصريح صريح يحدد النطاق.

## التحقق من هوية المستخدم وصلاحياته

```bash
id
```

عرض أوامر `sudo` المسموح بها للمستخدم الحالي:

```bash
sudo -l
```

## التحقق من تجزئة ملف

```bash
sha256sum downloaded-file.iso
```

قارن الناتج بالقيمة المنشورة في الموقع الرسمي للملف.

## فحص صلاحيات ملف حساس

```bash
stat /etc/ssh/sshd_config
```

## المنافذ المفتوحة محلياً

```bash
sudo ss -lntup
```

ابدأ بالفحص المحلي لمعرفة الخدمات المكشوفة فعلاً قبل أي فحص شبكي.

## اكتشاف أجهزتك داخل الشبكة المحلية

استبدل النطاق بنطاق شبكتك المصرح به:

```bash
sudo nmap -sn 192.168.1.0/24
```

`-sn` يكتشف الأجهزة المتاحة ولا يجري فحص منافذ.

## فحص منافذ جهاز تملكه

```bash
sudo nmap -sT -sV --top-ports 100 192.168.1.190
```

- `-sT`: اتصال TCP كامل.
- `-sV`: محاولة معرفة الخدمة وإصدارها.
- `--top-ports 100`: أكثر 100 منفذ شيوعاً لتقليل نطاق الفحص.

## حالة جدار UFW

```bash
sudo ufw status verbose
```

## محاولات الدخول عبر SSH في السجلات

```bash
sudo journalctl -u ssh --since "today" --no-pager
```

راجع النتائج بحثاً عن نشاط غير متوقع، ولا تنشر السجلات قبل إزالة العناوين أو البيانات الحساسة.
