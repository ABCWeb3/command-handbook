# الأساسيات وإدارة الملفات

## معرفة المجلد الحالي

يعرض المسار الكامل للمجلد الذي تعمل داخله:

```bash
pwd
```

## عرض الملفات

يعرض كل الملفات، بما فيها المخفية، مع الأحجام بصيغة سهلة القراءة:

```bash
ls -lah
```

- `-l`: عرض تفصيلي.
- `-a`: إظهار الملفات المخفية.
- `-h`: أحجام مثل `2K` و`15M`.

## الانتقال بين المجلدات

```bash
cd /path/to/directory
```

العودة إلى المجلد الأب:

```bash
cd ..
```

## إنشاء مجلدات متداخلة

```bash
mkdir -p projects/linux/notes
```

الخيار `-p` ينشئ المجلدات الأب غير الموجودة ولا يعرض خطأ إن كان المجلد موجوداً.

## نسخ ملف بأمان تفاعلي

```bash
cp -i source.txt destination.txt
```

الخيار `-i` يطلب التأكيد قبل استبدال ملف موجود.

## نقل ملف أو إعادة تسميته

```bash
mv -i old-name.txt new-name.txt
```

## قراءة بداية ملف ونهايته

```bash
head -n 20 file.txt
```

```bash
tail -n 20 file.txt
```

لمتابعة ملف سجل لحظة بلحظة:

```bash
tail -f /var/log/syslog
```

اخرج بواسطة `Ctrl+C`.

## البحث عن ملف بالاسم

```bash
find . -type f -iname "*.conf"
```

- `.`: ابدأ من المجلد الحالي.
- `-type f`: ملفات فقط.
- `-iname`: بحث غير حساس لحالة الأحرف.

## البحث داخل الملفات

```bash
grep -Rni -- "search text" .
```

- `-R`: بحث داخل المجلدات.
- `-n`: إظهار رقم السطر.
- `-i`: تجاهل حالة الأحرف.

إذا كان `ripgrep` مثبتاً فهو أسرع غالباً:

```bash
rg -n "search text" .
```

## معرفة مساحة الأقراص

```bash
df -h
```

معرفة حجم مجلد واحد:

```bash
du -sh /path/to/directory
```

## فحص الصلاحيات

```bash
stat file.txt
```

إضافة صلاحية التنفيذ لمالك ملف سكربت:

```bash
chmod u+x script.sh
```

> [!CAUTION]
> تجنب نسخ أوامر الحذف مثل `rm -rf` دون فهم المسار والتحقق منه؛ الاسترجاع قد لا يكون ممكناً.
