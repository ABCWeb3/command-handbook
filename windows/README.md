# أوامر Windows

سيضم هذا القسم أوامر **PowerShell** و**Command Prompt** بنفس التنسيق العربي الموحد.

## بداية سريعة

معلومات النظام في PowerShell:

```powershell
Get-ComputerInfo
```

عرض إعدادات الشبكة:

```powershell
Get-NetIPConfiguration
```

اختبار منفذ TCP:

```powershell
Test-NetConnection -ComputerName 192.168.1.190 -Port 5000
```
