# إدارة البرامج في macOS

## تطبيقات النظام

```bash
ls -1 /Applications
```

## Homebrew

```bash
brew search package-name
```

```bash
brew install package-name
```

```bash
brew list
```

```bash
brew update && brew outdated
```

```bash
brew upgrade package-name
```

## تطبيق رسومي عبر Cask

```bash
brew install --cask application-name
```

> [!IMPORTANT]
> تثبيت Homebrew نفسه ليس مطلوباً لاستخدام macOS؛ استخدم المصدر الرسمي فقط إن احتجته.
